# Ask FFC for Help

FFC is run by volunteers and support is best-effort. A clear, complete first
message is the fastest way to get help — it saves a round of "which site? what did
you see?". Your job is to work out whether FFC is actually needed and, if so, write
that message for them.

## 1. Is this FFC's to do?

**Owner can usually do it (offer to help directly):** wording, photos, contact info,
team members, posts, events — via the **edit-my-site** and **post-an-update** skills.
Personal account setup and the prerequisites — via **ffc-getting-started**.

**FFC needs to do it:**
- GitHub repository invitation missing, expired, or for the wrong username
- Domain, DNS, security-certificate ("not secure") warnings, or the site not loading
  at its domain
- Charity email (Microsoft 365) setup, access, or lost mailbox access
- A change that's approved but can't be published (repository rules block the
  merge), or a failed check that can't be fixed with a content change
- Footer details that come from the charity's FFC application (legal name, EIN)
- Adding analytics, tracking, forms, or other third-party services
- Application status, approvals, or orders in the FFC client portal
- Anything involving money, the Terms of Service, or removing someone's access
- **Possible security problem** — a compromised account, an unexpected admin, a
  suspicious change. Treat as urgent: tell them to change the affected password and
  turn on MFA now, then contact FFC.

## 2. Draft the message

Gather what's missing, then write a short message they can copy. Include:

- Their name and role, and the charity's name
- The site address and/or repository (e.g. `FreeForCharity/FFC-EX-yourcharity.org`)
- Their GitHub username, if it's about access
- What they were trying to do, what they did, and what happened — exact error text
  if there was one (suggest a screenshot)
- How urgent it is, and why (e.g. "event this Saturday")

Example:

> Hi — this is Jane Doe, treasurer at Example Food Pantry
> (github.com/FreeForCharity/FFC-EX-examplefoodpantry.org). I approved a change to
> our donate link today, but GitHub says the pull request can't be merged because of
> branch rules. My GitHub username is JaneDoe. Not urgent — sometime this week is
> fine. Thank you!

**Never include passwords, recovery codes, or verification codes** in the message.
FFC will never ask for them.

## 3. Where to send it

Current FFC contact details are on https://ffcadmin.org/site-owner/ (under "Good
habits and getting help"). Point them there rather than quoting contact details from
memory, so they always get the current ones. Charities that have applied can also
use the FFC client portal at https://freeforcharity.org/hub.

Set expectations kindly: FFC volunteers reply as soon as they can, but there's no
guaranteed response time. If it's been several days, offer to draft a polite
follow-up.
